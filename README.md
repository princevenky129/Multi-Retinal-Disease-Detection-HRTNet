# Multi-Retinal Disease Detection Using Hybrid Transformer (HRTNet)

## Project Overview
HRTNet is a deep learning project designed to detect multiple retinal diseases from fundus images using a hybrid architecture that combines Convolutional Neural Networks (CNNs) and Vision Transformers.

The project aims to learn both local image features and global contextual information to support multi-label retinal disease classification.

## Objectives
- Detect multiple retinal disease categories from retinal fundus images.
- Combine CNN-based feature extraction with Transformer-based feature learning.
- Evaluate model performance using classification metrics.
- Provide visual explanations to help interpret model predictions.

## Dataset
**ODIR-5K (Ocular Disease Intelligent Recognition)**

The dataset contains retinal fundus images associated with multiple ocular conditions. Access to the original dataset may be required to reproduce the experiments.
